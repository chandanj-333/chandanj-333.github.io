# Background music

Place your music file here and name it exactly:

    wedding-music.mp3

The site will automatically show the floating music button when this file exists.
If the file is missing, the music button stays hidden — nothing else breaks.

Tips
- Keep it under ~3 MB so it loads quickly on mobile data.
- Prefer a soft instrumental (veena, flute, nadaswaram) — it loops.
- Only use music you have rights to publish.
